# Muhammad Ahmad - AI Developer Portfolio

A modern, animated portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern Design** - Glass morphism effects, gradient accents, and smooth animations
- **Responsive** - Fully responsive across all devices
- **Dark Theme** - Beautiful dark theme with animated background
- **Interactive** - Cursor glow effects, hover animations, and scroll-triggered animations
- **Fast** - Optimized for performance with Next.js

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Deployment:** Vercel

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

## 🚀 Deployment

### Deploy to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Deploy!

Or use the Vercel CLI:

```bash
npm i -g vercel
vercel
```

## 🎨 Customization

To customize the portfolio with your own information:

1. Edit the data in each component file under `/components`
2. Update the metadata in `app/layout.tsx`
3. Modify colors in `tailwind.config.js`
